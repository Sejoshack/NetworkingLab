# NetLab Quest

A game-style networking lab. Walk through rooms, open routers, switches and PCs, run commands, follow guided missions, and test yourself with a quiz.

## Run it
Open `index.html` in any modern browser (double-click it). No install needed.

## Push to GitHub
```
cd netlab-quest
git init
git add .
git commit -m "Initial NetLab Quest"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/netlab-quest.git
git push -u origin main
```
Optional: in the repo's Settings > Pages, choose the main branch to play it online.
